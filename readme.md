<h1 align="center">📆 Gemini AI Calendar Assistant</h1>

Live Url - https://calender-ai-frontend.onrender.com/

An intelligent calendar assistant that integrates with Google Calendar via API and uses Gemini (Google’s LLM) through LangChain to understand natural language commands like:

“Schedule a meeting with Rahul at 5pm tomorrow”

“Cancel my call with the doctor”

“Do I have any events on 5th July?”

🚀 Features
✅ Natural language command handling
✅ Google Calendar integration
✅ Supports:

Booking appointments
Cancelling appointments (by name)
Listing all events

Finding events on a specific date
✅ Uses LangChain’s agent + tool system with Gemini
✅ Clean Streamlit frontend for user interaction

Tech Stack

LangChain – Tool-based reasoning + Gemini LLM
Gemini 1.5 Pro – Natural language understanding
FastAPI – Backend API layer
Streamlit – UI for user queries
Google Calendar API – Actual calendar operations
Deployment - Github and Render
